AMAugment Memory

SOBRE

Memória pessoal de escolhas, não tier list.

O Augment Memory organiza os augments que aparecem nas suas partidas recentes e mostra frequência, colocação média, Top 4 e parceiros repetidos.

Objetivo

Ajudar você a lembrar do contexto em que costuma escolher cada augment, sem transformar uma amostra pessoal em recomendação universal.

Dados

As consultas passam pelo backend gamer server-side. Nenhuma chave Riot fica no navegador.

ABOUT

Personal choice memory, not a tier list.

Augment Memory organizes augments from your recent matches and shows frequency, average placement, Top 4 rate and repeated partners.

Goal

Help you remember the context in which you tend to choose each augment without turning a personal sample into a universal recommendation.

Data

Lookups go through the server-side gamer backend. No Riot key is exposed in the browser.
